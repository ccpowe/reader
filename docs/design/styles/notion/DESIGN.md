# notion 风格包 v0.2 · 使用与判断规则

> 外观以 CSS 类为准，不要自己重写组件样式；需要新组件时，先组合现有的类，确实不够再新建同前缀（`nt-`）的类，并记录理由。
> 数值看 `tokens.css`，组件看 `notion.css`，长什么样看 `components.html`。本文件只写**判断**，不写外观。
> 优先级：`DECISIONS.md`（唯一事实来源）> 原版采集 / analysis > 先前应用的一致做法 > 草稿。第 9 节列出还没写进 DECISIONS 的取舍。

## 1. 使用说明

- 引入：`tokens.css` → `notion.css` →（产品的）`project-tokens.css` → `project.css`。根元素（通常是 `body`）加 `.nt-app`。
- 产品自己的类放进 `project.css`，并在 `DESIGN.project.md`「新增类及理由」写一行；通用的类提回本包，记进 CHANGELOG。
- 自检：`node checks/lint.mjs <项目目录>`，有问题时退出码为 1。
- **状态类**（全包统一，不要另起名字）：

| 类 | 含义 | 用在 |
|---|---|---|
| `is-selected` | 当前选中项；导航里的当前页（另加 `aria-current`）；菜单 / 搜索里方向键停住的那一行 | 行、tab、chip、菜单项、结果行、框选的表格行 / 块 |
| `is-current` | 另一处面板正在显示它的内容 | 在 Side Peek 里打开的表格行、大纲当前条 |
| `is-open` | 浮层已打开；行的菜单开着；折叠项已展开 | popover、modal、tooltip、toast、search、peek、layer、行、`.nt-disclosure` 的父元素 |
| `is-on` | 开关 / 勾选的受控写法（也可以直接用原生 `:checked`）；图标按钮的"已开启" | switch、checkbox、icon-btn |
| `is-error` | 输入校验失败 | `.nt-input` |
| `is-working` | 正在后台处理 | `.nt-progress` |
| `is-faded` | chrome 暂时让位（打字、搜索打开） | `.nt-topbar` |
| `is-hover` `is-active` `is-focus` | 强制状态，**只给样板页 / 截图用** | 所有可交互类 |

- 禁用：用原生 `disabled` 或 `aria-disabled="true"`，不要加类。控件整体变淡；菜单项例外，只变灰。
- 焦点环由 `:focus-visible` 自动给出，不要写 `outline`。嵌在面板里的裸文字输入（搜索输入、评论输入、`.nt-editable`）实测没有环，只显示光标。
- **字体**：只用系统字体栈 `--font-sans`；代码用 `--font-mono`。不引入网页字体。字距保持 normal，唯一例外是行内 `OPEN`（`--letter-spacing-quick-action`）。
- **图标**：单色线性图标，`--icon-lg` 网格、描边 `--icon-stroke-width`、圆角端点，颜色用 `currentColor`。实心字形只用于 Home、表格折叠三角、Upgrade，以及由圆点组成的 `···` 和拖拽把手；勾和下拉箭头在小尺寸下描边可以略粗。来源二选一：项目内手绘 inline SVG，或 Lucide（`strokeWidth` 取 `--icon-stroke-width`）。一个产品里只用一种，其他图标库会被 lint 拦下。尺寸用 `.nt-icon--xs…xl`。
- 页面图标用 emoji 或通用的 page 线框图标。头像用字母头像（`.nt-avatar`）。

## 2. 设计意图（从原版归纳）

1. **内容压过界面**：正文用深色，界面文字是偏灰的 UI 字号。每个面板只有标题用 700。
2. **一个强调色，少用**：蓝色只出现在第 4 节白名单里。红色只表示破坏性操作。
3. **一种中性交互底色**：列表 / 菜单 / tab 的 hover、选中、键盘当前行都是同一层暖灰。选中只多一个"文字变深"。框选和"在详情里打开"是另一回事，用实测的蓝色 halo。
4. **全部是暖灰**：文字、底色、线条没有纯黑，也没有冷灰。阴影和遮罩按实测值（含中性黑）。
5. **浮起靠阴影，不靠边框**：浮层的边缘是阴影里自带的细圈。唯一例外是搜索预览卡（实测阴影 + 实线）。页内内容是平的。
6. **分组先靠留白**：细线只用于表格网格、设置分节、菜单分组，以及面板的底栏 / 分区边（侧栏底栏、插入菜单底栏、视图栏、搜索底栏、评论区）。
7. **反馈要快**：行高亮约等于瞬时（`--duration-instant`），面板 `--duration-base`，只有装饰性的浮动按钮有弹性。

## 3. 规则分层

- **视觉层（必须遵守）**：颜色、字体、字号字重、圆角、阴影、细线、间距刻度、控件高度与内边距、动效时长与曲线、状态的表现。都在 `tokens.css` / `notion.css` 里，产品不能改。
- **`[模式]`（可以被具体产品覆盖）**：布局、交互默认值，见第 7 节。覆盖时在 `DESIGN.project.md` 写一句理由。
- **视图形态（由产品决定）**：有哪些页面、放哪些组件、表格有哪些列、侧栏有哪些分组、面板里的间距。本包不规定。

## 4. 需要判断的规则

**按钮怎么选**
- `--primary`：**每个面板**（主内容区 / Side Peek / 弹窗）最多 1 个，用于这个面板存在的理由（新建、保存、开始、邀请成员页的"邀请"）。有多种新建方式时用 `.nt-split`。
- `--secondary`（蓝色浅底）：和主动作相关、但不是主动作的辅助动作（复制链接）。一个面板里不超过 2 个，和 primary 不并排。同一个动作是不是 primary，看它是不是这个面板存在的理由，不看动作名。
- `--outline`：显示当前值、点开是一个选择（下拉、设置项选择器、排序方式）。弹窗里的"取消"也用它。
- 默认（ghost）/ `--muted`：顶栏动作、表格里的角色下拉、空状态里的下一步、低频操作。
- `--danger`：只给不可撤销的破坏性操作，只出现在"Danger zone"或删除确认弹窗里。菜单里的"移到回收站"不用红色。
- `.nt-icon-btn`：动作含义能被图标说清楚时才用，必须写 `aria-label`。图标意思不唯一时用带文字的按钮。

**组件怎么选**
- 可导航的列表 → `.nt-row`；设置左栏 → `.nt-nav-item`；搜索 / 快速跳转结果 → `.nt-result`。
- 临时出现的动作列表 → `.nt-popover.nt-menu`，放进 `.nt-layer__anchor` 定位；插入类菜单 → `--slash` + `__item--option`。
- 选择一个值：选项 ≤ 2 且立即生效 → `.nt-switch`；多个选项 → outline 按钮 + 菜单；同一数据的子集切换 → `.nt-tabs`；视图切换 → `.nt-tab--view`。
- 结构化记录 → `.nt-table`；按某个属性分组时 → `.nt-table__group`（分组值用 `.nt-status` / `.nt-tag`）；设置里的人员列表 → `.nt-table--simple`；正文里的小表 → `.nt-content-table`。
- 勾选框分两种：选行用的 `.nt-table__check` 是行内动作（见下）；表示**数据**的勾选框（是否完成）放进标题格，一直显示。
- 一条记录的详情 → `.nt-peek`（不打断列表）。必须打断、需要确认的 → `.nt-modal` + `.nt-dialog--confirm`。不打断的结果反馈 → `.nt-toast`：能撤销就带一个撤销按钮；不能撤销（已在弹窗里确认过）就只写结果。
- 评论 → `.nt-comments` 里放 `.nt-comment-list`；面板里的顺序：标题 → 属性 → 评论 → 正文。
- 可编辑的标题 / 正文 → 内层加 `.nt-editable`，外层仍是 `.nt-page-title` 等原来的类。
- 只给图标按钮做名称或快捷键提示 → `.nt-tooltip`，不要放说明文字。
- 没内容时：优先用一行 `.nt-empty-hint`（包括零结果搜索）；整片区域为空、而且需要引导下一步时，才用 `.nt-empty`。
- 加载中：已知形状的数据用 `.nt-skeleton`；搜索或查询进行中用 `.nt-progress.is-working`（查询结束就去掉）；小区域的等待用图标加 `.nt-spin`。
- 搜索预览卡里的内容用现有类组合（`.nt-h3` + 不可交互的 `.nt-props`），不另做缩小版排版。
- 正文强调：需要读者注意的一段 → `.nt-callout`；引用别人的话 → `.nt-quote`。不要用彩色文字来强调。

**颜色只能出现在这里**
- 蓝色：primary 按钮、secondary 按钮的文字和浅底、开关开、已勾选的勾选框、链接（界面和正文一样）、焦点环、在详情里打开的行（halo + 把手）、框选的行 / 块（halo）、搜索进度微光、通知点、New 徽标、搜索面板的圆形图标、"Upgrade"项。
- 红色：`--danger` 按钮、输入错误外圈。
- 数据色（`nt-tag--*`、`nt-status--*`）：只给**数据**分类。不用于导航、按钮、标题、身份标记。状态 pill 只有 gray / blue / green 三种。
- 其他地方一律只用暖灰。列表 / 菜单 / tab 的选中、hover 永远不用蓝底。图标按钮的 `is-on` 只变深，不变蓝。

**数量与层次**
- 每个面板只有一个 700 的标题（`.nt-page-title`）。Side Peek、弹窗各自算一个面板。
- 界面标签用 strong-muted 或 secondary 灰，选中后变深。内容用正文色。
- 行内动作（`__actions`、`OPEN`、选行勾选框、拖拽把手、树行展开箭头）只在 hover 或键盘聚焦时出现，静止的行只显示图标和文字。

## 5. 禁止事项

1. 文字、底色、线条不用 `#000`、冷灰、中性灰；不写 tokens 之外的颜色。
2. 不引入第二种交互色。不用蓝色或彩色做列表 / 菜单 / tab 的 hover、选中底色（框选和"在详情里打开"的 halo 除外）。
3. 行、菜单项、列表卡片、浮层都不加边框（浮层只用自带细圈的阴影；搜索预览卡例外）。
4. 面板标题以外不用 700。不用全大写标签（只有行内 `OPEN` 例外；中文不受影响）。
5. 表面和按钮不用渐变（加载微光除外）。
6. 搜索、菜单、Side Peek 不加遮罩，只有弹窗有遮罩。点外面关闭用透明的 `.nt-layer__catcher`。
7. 页内内容（callout、单元格、行、代码块）不加阴影。例外：hover 才出现的行内 `OPEN` 浮起按钮（实测）。
8. 交互反馈的动效不超过 `--duration-spring`（chrome 淡出 `--duration-slow` 和加载动画除外）。只有浮动按钮可以回弹。
9. 表格不做斑马纹，也不加外框（`.nt-prose` 里的表格同样）。
10. 不覆写 `nt-` 类的颜色、背景、边框、阴影、圆角，也不改控件的高度和内边距；不在 `nt-` 元素上写这些内联样式。宽度和位置属于布局，可以改。
11. 不用浏览器默认 outline 做焦点。按钮、行、tab、菜单项等控件不去掉焦点环（裸文字输入例外，见第 1 节）。

## 6. 动效与无障碍

- 所有动效都是 CSS transition，可以中途打断并反向。浮层收起时保留元素，去掉 `is-open`，不要立即卸载（否则看不到退场）。
- `prefers-reduced-motion`：本包去掉缩放、位移（含开关圆钮）和折叠箭头的旋转过渡，只保留透明度；微光停住；加载旋转（`.nt-spin`）保留，它是状态信息。产品自己的动效也照这个做。
- 键盘：菜单 / 搜索用方向键移动 `is-selected`，DOM 焦点留在菜单 / 输入框上，用 `aria-activedescendant` 指向当前行；Enter 选中，Esc 逐层关闭（最上层的先关）。开关和勾选框用原生 input。
- 层级：Side Peek 用 `--z-sidebar`；菜单、搜索、弹窗、toast、`.nt-layer` 用 `--z-overlay`。

## 7. `[模式]` 默认值（产品可以覆盖）

- 外壳：左侧侧栏 + 内容区顶栏 + 可滚动内容区，没有底栏。侧栏分组用小灰字标题，可折叠。
- 行级的次要动作在 hover 时出现：页面图标换成展开箭头，右侧追加 `+` / `···`。
- 文档页：居中单栏 `--layout-page-width`，标题上方留 `--space-80`。数据库页：全宽，两侧 `--space-96`。
- 记录详情在右侧 Side Peek 打开（`--layout-side-peek-width`），左边保持可用。
- 全局搜索：居中浮层（`--layout-search-*`），"列表 + 实时预览 + 底部键盘提示"。
- 插入菜单由 `/` 触发，带分组，快捷键右对齐。菜单离触发器 `--space-popover-offset`。
- 设置：内缩弹窗（`--size-scrim-inset-*`）+ 分组左栏。设置行左边是说明，右边是控件；"Danger zone"放最后。
- 浮动帮助按钮（`.nt-fab`）默认在右下角。
- 菜单可以用键盘操作；键盘当前行和 hover 看起来完全一样。

## 8. 文案语气（原版里观察到的）

- 标签是短动词短语，句首大写、其余小写（Add a property、New page、Close menu）。中文产品用简短的动宾结构，不加句号。
- 占位文字说明能做什么，以省略号结尾（Search or ask…、Add a comment…）。
- 状态用相对时间、放在次要位置（Edited 6m ago）。空值写一个词（Empty；中文用一个对应的词），用三级灰。
- 破坏性按钮把对象写全（Delete workspace，不写"删除"）。确认弹窗说清后果。"Danger zone"指放在最后的破坏性设置一节，节名用产品的界面语言。
- 快捷键写成 `Ctrl+K`、`esc` 这种原样，放在键帽（`.nt-kbd`）或菜单右侧。
- 不用感叹号，不用营销腔，不在界面文字里出现品牌名。

## 9. 已知不足与待定

- **D2 估计、待补采**：tooltip 外观、toast、代码块、引用、勾选态、确认弹窗（含宽度）、评论线程、Side Peek 进场动效。标注写在 `tokens.css` / `notion.css` 注释的 `[选定 D2]` 里。延续验证时如果明显不像，就按 D2 回去补采。
- **D2 列了、但 analysis 写 can't tell、没有可执行估计的**：公式、深色模式。补采前本包不提供。
- **根变量值、未实测**：pressed（`:active`）。CSS 里实现了，表现没在原版里看到过。
- **推导组件**（原版没有，由现有配方组合）：`.nt-empty`、`.nt-table__group`、`.nt-content-table`。
- 没有采到、本包**不提供**：危险按钮 hover、日期选择器、单选、滑块、看板 / 画廊 / 日历视图、侧栏折叠后的样子。需要时先组合现有类，并记录理由。
- 搜索面板底色 `--color-bg-search-panel` 是实测的半透明白，没有采到模糊（backdrop-filter），下面的内容会透出来。原版很可能有模糊，待补采；补采前不加。
- 细线 `--border-hairline-width` 待核：这个读数更像高 DPR 下的结果，复核采集记录前不改值。
- 推断值：输入框圆角、行内代码圆角（借用相邻实测值）、Side Peek 内容缩进、设置内容顶部间距、菜单离触发器的间距。
- 冻结首列的分隔线（`--color-frozen-divider`）需要滚动状态，本版只有 token，没有类。
- 图标的具体字形是私有的，只知道盒子尺寸和颜色。
- 打包时的取舍已写进 DECISIONS D3–D8（正文链接按 D7 用继承色 + 灰色下划线）。
