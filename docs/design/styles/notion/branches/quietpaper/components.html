Quietpaper v0.7 组件样板

外观以这里的 CSS 类为准，不要自己重写组件样式。每组旁边写类名和一句用法；hover / pressed / focus 用强制类 is-hover is-pressed is-focus 并排展示（只在样板页用），真实状态类是 is-selected is-current is-open is-on is-error is-working。本页只有通用类；产品专属组件见各项目自己的样板页。

图标 / 语言徽标 / spinner

qp-icon --xs --md — 只用 Tabler outline；默认 16px、全灰（D6 / D9 / D10）。
qp-icon--strong --disabled --danger --ai — strong 给 hover / 激活；danger 只给删除；ai 只给"AI 正在工作"。
qp-iconbox + qp-lang qp-lang--{ts,js,py,md,json,other} — 代码等非文档文件的标识；缩写 2 个字母，最多 3 个。
qp-icon qp-spinner（加在 Tabler loader-2 上）— 唯一的加载指示；reduced-motion 下也保留旋转。

按钮

qp-btn（= secondary）— 表单内的普通操作、列表行里的非当前操作。
qp-btn qp-btn--primary — 每个视图最多 1 个；列表里逐行相同的操作只有一行用 primary（默认当前项）。
qp-btn-split > qp-btn--primary × 2 — 主操作 + 下拉；中间留 --border-width 的缝；整组算视图里的 1 个 primary。
qp-btn qp-btn--soft — 主操作旁的次级强调；每个视图最多 1 个，不在列表里逐行重复。
qp-btn qp-btn--ghost — 工具栏、横栏、行内操作、"+ 动词"入口；开关类按钮打开时加 is-on。
qp-btn qp-btn--danger — 只在不可逆 / 批量操作的确认弹窗里，只用于破坏性操作。
qp-btn qp-btn--ghost qp-btn--inline — 嵌在列表行里的小文字按钮（行类时长）。
qp-icon-btn / qp-icon-btn--xs — 独立图标按钮 / 嵌在行里的图标按钮；有 tooltip 写明含义。

输入框 / 下拉 / 搜索框 / 键帽

qp-input（input / textarea）+ qp-label qp-desc qp-field-error — 失焦时校验；出错加 is-error 或 aria-invalid，错误文字放字段下方。
qp-select + __value __chevron — 下拉触发器 = secondary 按钮外观；选项菜单用 qp-popover qp-menu。
qp-search + qp-kbd — 导航内搜索框，右侧键帽显示快捷键；键帽文字是 secondary（不能用 tertiary）。

勾选框 / 开关

input[type=checkbox].qp-checkbox — 多选；填充用 accent。

没有 disabled / indeterminate 样式：参考数据和规范里都没有，不编。

button.qp-switch[role=switch][aria-checked] > qp-switch__knob — 立即生效的设置；旁边不放"保存"。

没有 disabled / hover 样式：规范没有给出，不编。

列表行 / 树行 / 搜索结果

qp-row qp-row--nav + __label __trail __hover — 导航树 / 侧边栏入口；选中只改背景和文字灰阶，字重不变（D4）。
