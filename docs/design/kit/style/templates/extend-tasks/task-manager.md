# 探针任务：团队任务管理（固定任务，用来检验风格包）

> 探针任务一旦用过就不要改；改了就是新任务，结果不能和以前比。
> 它故意覆盖了大部分通用组件：导航、列表、表格、表单、弹窗、菜单、空状态、toast。

## 视图
1. **侧边栏 + 任务列表**：侧边栏有工作区名、搜索、3 个项目（其中一个展开显示子项）、设置入口。主区是"我的任务"列表，按状态分组（进行中 / 待办 / 已完成），每行：勾选框、标题、标签（1～2 个）、截止日期、负责人头像。20 条任务，标题长短不一，有一条特别长，有几条没有截止日期
2. **任务详情**：从右侧滑出的详情面板。标题（可编辑）、描述（多段文字 + 一个代码块 + 一个列表）、属性（状态下拉、负责人、截止日期、标签）、评论区（3 条评论，其中一条是 AI 写的）、底部评论输入框
3. **设置弹窗**：左侧导航（通用 / 成员 / 通知），"成员"页：成员表格（8 行：头像、名字、邮箱、角色下拉）、"邀请成员"主按钮；"通知"页：4 个开关，每个带一句说明
4. **命令面板**：Cmd/Ctrl+K 打开，有最近访问和搜索结果
5. **空状态与反馈**：一个没有任务的项目页（空状态）；完成任务后底部出现 toast（带撤销）；删除项目的确认弹窗

## 交互
勾选完成、打开 / 关闭详情面板、切换设置页、命令面板键盘上下选择、Esc 逐层关闭。数据用假数据。
