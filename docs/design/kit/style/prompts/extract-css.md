你是一名设计系统工程师。本目录有：
- `DECISIONS.md`：所有已拍板的风格决策，是**唯一的事实来源**
- `DESIGN-draft.md` + `tokens.css`：从参考产品拆出来的风格规范草稿（纯文字）
- `analysis.md`：拆解记录（证据）
- `apps/`：几个只凭草稿做出来的小软件（笔记、番茄钟……），用户已经确认它们有原版的感觉。它们的 CSS（尤其是各自的 `src/components.css`）是这份规范最具体的落地；同一个组件在几个软件里做法不同时，选最贴近草稿和 capture 的那种
- `NAME.md`：风格包名字和类名前缀（例如 `quietpaper` / `qp-`）
- `example/`（可选）：另一个已完成的风格包，只参考**文件形式**，不参考视觉数值

## 背景
文字规范越写越长，执行的人每次都要重新读懂再自己实现，矛盾和歧义越来越多。要换一种形式：**外观交给代码，文字只写判断**。

## 产出（全部放在 `out/`）
1. **`tokens.css`**：整理后的全部数值，按角色命名，每个值带来源标签 `[测量]` `[估计]` `[推导]` `[选定 Dn]`（n 对应 DECISIONS 编号）
2. **`<名字>.css`**：通用组件类，只依赖 tokens.css
   - 覆盖规范里的所有组件和它们的状态（hover / active / selected / focus-visible / disabled / loading）：按钮各变体、输入框、下拉、开关、勾选框、列表行 / 树行、标签和徽标、头像、callout、菜单 / popover、tooltip、弹窗、toast、空状态、骨架屏、表格、标签页、键帽、状态点、内容块（代码块、行内代码、引用、表格）……
   - 类名统一前缀，BEM 风格（`<前缀>btn <前缀>btn--primary`）
   - 状态用统一状态类（`is-selected` `is-current` `is-open` `is-on` `is-error` `is-working`）；`is-hover` 等强制状态类只给样板页用
   - 动效、reduced-motion、焦点环都写在这里
3. **`components.html`**：样板页。引用上面两个 CSS，**展示每个类的每种状态**，每组旁边写类名和一句用法。双击能在浏览器里打开（字体可以走 CDN）。示例文案用通用内容
4. **`DESIGN.md`（≤ 150 行）**，只写：
   - 使用说明："外观以 CSS 类为准，不要自己重写组件样式；需要新组件时，先组合现有的类，确实不够再新建同前缀的类，并记录理由"；状态类清单；字体和图标的引入方式
   - 设计意图和总原则（从原版归纳，不加个人偏好）
   - 规则分层：视觉层必须遵守；`[模式]`（布局、交互默认值）可以被具体产品覆盖；视图形态由产品决定
   - 需要判断的规则：什么场景用哪个组件、怎么选变体、一个视图里最多几个 primary、颜色只能出现在哪里……
   - 禁止事项；`[模式]` 默认值；文案语气；已知不足
   - **不要**再写具体外观描述，那些已经在 CSS 里了
5. **`checks/lint.mjs`**：`node lint.mjs <项目目录>`，检查项目里的 CSS / TSX：写死的颜色（tokens 之外）、写死的 px / ms（布局几何可以白名单）、引入了规定之外的图标库、重新定义了本包组件类的视觉属性（颜色、背景、边框、阴影、圆角）、用了不存在的组件类、`var()` 引用了不存在的变量。输出问题清单和总数，有问题时退出码非零。有 `example/` 的话可以改造它的 lint
6. **`DECISIONS.md`**（原样复制）、**`CHANGELOG.md`**（第一节 v0.1）
7. **`MIGRATION.md`**：草稿里每块内容去了哪里（CSS / DESIGN / lint / 删除），删除的写明理由

## 原则
- DECISIONS.md 优先，和它冲突的旧内容一律以它为准
- 提取依据的优先级：DECISIONS.md > `analysis.md` 里的原版实测值 > apps 的实际实现 > DESIGN-draft.md。apps 只用来学"组件怎么拆、类怎么组织"；apps 和原版实测不一致的地方，以原版为准
- 每一个取舍（比如"apps 里删除项用了红色，原版没有，不采用"）都追加为 DECISIONS.md 的一条，不要只写在 CHANGELOG 里
- **不知道的不要发明**：宁可让组件少一种状态，也不要凭空编一个
- 完成后用你写的 lint 检查一遍 apps 里的每个软件，结果写进 MIGRATION.md
