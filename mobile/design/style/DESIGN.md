# DESIGN.md — Quietpaper v0.7

> 事实来源：`DECISIONS.md`（D1–D19，随包附带），冲突时以它为准。本文只写**判断**；外观全部在 CSS 里，数值全部在 `tokens.css` 里。版本记录：`CHANGELOG.md`。
> 文件：`tokens.css`（数值）→ 项目 token（`--qp-` 前缀）→ `quietpaper.css`（通用组件）→ 项目 CSS（产品组件）。样板：`components.html`。检查：`node checks/lint.mjs <项目目录>`。
> 本包只放可复用的通用规格（D16）。产品自己的组件、判断和对模式层的覆盖写在项目的 `DESIGN.project.md`。

适用：长时间阅读写作的知识管理 / 文档工具、中高密度生产力工具（文件树、Markdown + LaTeX、划词评论、代码阅读）。不适用：营销页、强品牌页面、数据大屏。

## 0. 使用说明（必读）
- **外观以 CSS 类为准，不要自己重写组件样式。** 不改 `qp-` 类的颜色、背景、边框、阴影、圆角；不写死颜色、px、ms（lint 会拦）；组件里用作尺寸的 vw / vh / 百分比上限也提成 token（lint 查不到，自己注意；定位、居中用的 50% / 100% 不算）。
- 需要新组件时：**先组合现有的类**（例：带操作的提示卡 = `qp-callout` + `qp-btn` + `qp-tag qp-status`）；确实不够，再新建 `qp-` 类——通用的进 `quietpaper.css`，产品专属的进项目 CSS——只用 token，并在 `CHANGELOG.md`（通用）或 `DESIGN.project.md` 的"新增类及理由"（产品）记一行"为什么现有类不够"。
- 状态用类表达。通用状态类：`is-selected` `is-current` `is-open` `is-on` `is-error` `is-working`；项目可以增加自己的 `is-*`，在项目 CSS 里定义、在 `DESIGN.project.md` 列出。`is-hover` / `is-pressed` / `is-focus` 只给样板页和截图用。
- 字体：代码字体 JetBrains Mono 用 `@fontsource/jetbrains-mono` 打包（D8）；中文用系统字体、不打包（D14）；公式用 KaTeX 自带字体（D15）。图标只用 `@tabler/icons*`，加 `qp-icon` 类（D6）。
- 拿不准时：看 `components.html` 里同类组件怎么用；还拿不准，选更克制的那个（D12）。

## 1. 设计意图与总原则
1. **内容是唯一主角**。chrome 比内容降一级；行内操作平时藏起来，hover / 聚焦时才出现（常驻的例外见 3.1 末条）。
2. **颜色要克制**（D12）。底子是中性灰；强调色只出现在 3.2 列出的位置；其余颜色只出现在**面积很小、有意义**的地方：emoji、语言徽标、删除图标、状态圆点、状态反馈、标签、正文里的评论锚点和查找命中、AI 工作中的瞬时色（D11）。代码语法高亮（D7）按代码自己的规则，不受这一条限制。拿不准时选更克制的那个。
   - **阅读区**（正文、代码、评论内容）不加装饰色；点缀色只放在 chrome 的小元素上，用浅底 / 小面积，不用实心色块（D19）。阅读区里允许的颜色只有：语法高亮、正文行内评论锚点和查找命中（黄）、项目层声明为必需语义的整行底色。带行号的整行（代码行等）上的评论标记（整行底、竖线、引文条）一律中性（D17）。
3. **交互反馈只有一个维度：背景叠加层**。hover / pressed / selected 只改背景；允许的附带变化只有"文字灰阶升一级"和"图标升到 strong"。不位移、不缩放、不加阴影、不改字重。行附件的显隐（第 1 条，以及图标原位换成 chevron 这类）是"出现了什么"，不算交互反馈，不受这一条限制。
4. **AI 和人平等呈现**（D11）。靠图标形状和「AI」徽标区分，不靠颜色；AI 色只表示"正在工作"这一瞬间。
5. **可撤销优先于确认**。能撤销的操作直接做并给 Undo，不弹确认框。

## 2. 规则分层（D13）
- **视觉层**（CSS 类 + 本文没有 `[模式]` 的规则）：必须遵守。
- **模式层**（标 `[模式]`）：从参考产品学来的布局、组成、交互默认值；PRODUCT 另有规定时以 PRODUCT 为准，但被覆盖的部分仍然用本包的类来画。覆盖写进 `DESIGN.project.md`；没写到的部分仍按本文默认值。
- **视图形态**（文档页 / 代码页 / 列表 / 表单……）永远由 PRODUCT 决定。
- 判断：回答"长什么样"→ 视觉层；回答"放哪、由什么组成、何时出现、按了会怎样"→ 模式层。

## 3. 需要判断的规则

### 3.1 按钮怎么选
| 场景 | 用 |
|---|---|
| 视图里最重要的那一个操作 | `qp-btn--primary`，**每个视图最多 1 个** |
| 主操作旁的次级强调 | `qp-btn--soft`，每个视图最多 1 个，不在列表里逐行重复 |
| 表单里的普通操作、列表行里非当前项的操作 | `qp-btn`（secondary） |
| 确认 / 取消对 | 确认：`qp-btn`（它就是视图主操作时用 primary）；取消：在弹窗里 `qp-btn`，在卡片 / 浮层里就地展开的确认步骤用 `qp-btn--ghost` |
| 工具栏、顶栏、视图内横栏、行内操作、"+ 动词"入口、开关类按钮 | `qp-btn--ghost`（开关打开加 `is-on`）；行内小按钮加 `--inline` |
| 只有图标 | `qp-icon-btn`；嵌在行里用 `--xs`；必须有 tooltip / aria-label |
| 不可逆或批量的破坏性操作，且在确认弹窗里 | `qp-btn--danger`。其他任何地方都不用 |
- `qp-btn-split`（主按钮 + 下拉）整组算 1 个 primary。
- **"视图"**＝一个独立工作区：一个标签页 / 窗格、一个侧面板、一个弹窗。两个视图同屏各自计数。浮在视图上的气泡卡、工具条不单独算视图，里面不放 primary。
- **列表里每行都有同一个操作**（如"打开"）：只有一行用 primary，其余行 secondary——不用 soft。哪一行拿 primary 是 `[模式]`：默认是当前项（键盘当前项 / 展开项）；产品可以换一个定义（例如"最早的一条"），写进 `DESIGN.project.md`。
- "拒绝""取消""关闭仍有进程在跑的对象"不是破坏性操作，不用 danger。
- 加载中：spinner 换掉前置图标，文字和宽度不变；短于 `--delay-loading` 不显示。
- 行内操作常驻的只有：当前项自己的操作、承载信息的计数 / 状态、项目在 `DESIGN.project.md` 里逐条列出的；其余 hover / 聚焦时出现。触屏上 `···` 常驻。

### 3.2 颜色与强调
- **强调色只出现在**（穷举）：primary / soft 按钮、开关和勾选框打开态、正文链接、焦点环、文字选区。导航选中、状态圆点、计数**不用**强调色，也不用和强调色同值的颜色（所以 Status 圆点只有 gray / green）。
- **一行界面行**（列表 / 树 / 表格 / 菜单 / 面包屑行；标签栏按每个标签各算一行）**最多一个有颜色的元素**（emoji、语言徽标、状态圆点、彩色标签、有色计数都算）。代码内容（语法高亮）不计。唯一例外是**状态汇总**：几个数字各配自己的状态圆点（"3 在跑 · 1 出错"），整组算一个元素。同一行里有多个候选时，产品在 `DESIGN.project.md` 里定优先级。
- 图标默认全灰（D9 / D10）；不按主题、不按对象类型上色。对象 / 功能图标的固定色只有删除（`--color-icon-danger`）和 AI 工作中（`--color-icon-ai`）；状态反馈图标用状态色 token（`--color-success` / `--color-warning` / `--color-danger`），出错不用 `--color-icon-danger`（两者现在同值，区别在角色）。
- 对象图标优先级：用户设的 emoji > 语言徽标 > 灰色类型图标；不并排。彩色图形不大于图标框。
- **文字灰阶**（D2）：tertiary 只给"不读也不影响使用"的字（元信息、占位符、快捷键提示、行号、一般分组标题）；说明、标签、错误、空状态、"+ 动词"入口、键帽、**读懂才能操作的分组标题**一律 secondary 或更深（分组标题用 `qp-sidebar__heading--strong` / `qp-menu__heading--strong`）；disabled 灰只给禁用控件。
- 计数：可以不读的用 `qp-count`（tertiary）；需要读的用灰色 `qp-tag`（或项目的灰色计数类）。只有"需要用户处理"的计数允许有色：`--color-danger-bg` 底 + `--color-danger-text` 字（D18），不用实心色块，也不用"灰计数 + 色点"；类和放在哪些入口由项目层定。
- 行尾要读的状态文字 / 元信息用 `qp-row__hint--strong`；`qp-row__hint`（tertiary）只放快捷键这类可以不读的提示。
- 状态圆点永远和文字（或 tooltip 文字）一起出现；不占对象图标位（图标位只放 emoji / 语言徽标 / 灰色类型图标）。

### 3.3 文字层级
- chrome 默认 ui 级，内容默认 body 级；同一段内容里不混用。评论正文、AI 回答是内容（body）；组件里的作者行是独立的 chrome 子组件，不算混用。输入框里用户输入的字（命令面板）可以是 body 级。
- **同一行 / 同一子组件**（一行菜单项、一行结果、一个标题、一条底栏）里最多 ui + 一个辅助级别（caption / desc / micro 三选一）；一个大组件由多个子组件组成时各自计算。键帽 `qp-kbd`、计数徽标、语言徽标是附着的图形，不算级别。作者行是唯一允许 ui + caption + micro 的一行。
- 每个文档页 1 个 display 标题（空文档时就是 `qp-title-input`）；正文标题只靠字号分级，加粗用 600，选中项不加粗。
- 分组标题是 caption 级，不随嵌套层级变字号；嵌套层级靠缩进和留白表达，所以下一级的行可以比上一级的标题字大。
- 界面只有 sans 和 mono 两个字体族；例外只有公式（KaTeX 字体，D15）和产品提供的阅读设置。
- 表格、数值、日期、时长用等宽数字；单行 UI 文字溢出用省略号，不换行。

### 3.4 组件怎么选
| 需要 | 用 | 不用 |
|---|---|---|
| 给页面内容分组 | 留白 + 标题；需要强调时 `qp-callout` | 描边卡片、阴影卡片、卡片套卡片 |
| 结果在视野内（开关、展开、输入） | 不额外反馈 | Toast |
| 结果在视野外（单个对象的移动 / 删除、复制链接） | `qp-toast`（可撤销时带 Undo） | 弹窗 |
| 校验 / 权限 / 失败 | `qp-msg`（类型按严重度）；字段错误放字段下方 | Toast |
| 视图级状态（断开、只读、看的是别处的副本） | `qp-msg--bar`；同一视图只放一条，取最严重的类型 | 多条叠放 |
| 列表 / 预览 / 结果加载 | `qp-skeleton` | 整页 spinner |
| 按钮触发的操作在跑 | 按钮内 `qp-spinner` | 骨架屏 |
| 需要和列表对照看的单条记录 `[模式]` | `qp-drawer` | 弹窗 |
| 低频全局配置 `[模式]` | `qp-overlay` + `qp-modal`（左导航） | Drawer |
| 不可逆 / 批量操作的事前确认 | `qp-overlay` + `qp-modal qp-modal--sm`（单列） | Drawer、行内确认 |
| 全局跳转 / 搜索 `[模式]` | `qp-command`；默认不垫遮罩，产品要遮罩时外层套 `qp-overlay` | 弹窗 |
| 需要长时间编辑的单个对象 `[模式]` | 新页面（从 Drawer 升级） | Drawer |
| 选一个值 | `qp-select` + `qp-menu`（长菜单限高 `--layout-menu-max-height`） | 一排按钮 |
| 立即生效的二元设置 | `qp-switch`（旁边不放"保存"） | 勾选框 + 保存 |
| 多选 / 列表里批量选 | `qp-checkbox` | 开关 |
| 同级视图切换 | `qp-tab`（分段）/ `qp-tab--view`；设置左栏用 `qp-row--menu` | 下划线 tab |
| 分类属性（Select / Status、对象所在的位置 / 环境） | `qp-tag` / `qp-tag qp-status` | 按钮、彩色文字 |
| 代码 | 正文里一小段 → `qp-code`；成段 → `qp-codeblock`；整个文件 → `qp-code-lines` | 给行内代码着色 |
| 图片 / 图表的说明 | `qp-figcaption`（`qp-prose` 里的 `figcaption` 自动套用） | 正文段落 |
| 线程里回复 | `qp-thread__reply` + `textarea.qp-input` | 另开弹窗 |
| 列表页页头 | `qp-h2` + `qp-desc` + 右侧按钮（筛选开关 ghost `is-on`，批量操作 secondary） | 描边工具栏 |

### 3.5 动效
- 需要动画：空间位置 / 层级变化（浮层、弹窗、chevron、侧边栏宽度）和状态切换（开关、勾选）。
- hover 底色：**行类元素**（列表行、菜单项、单元格、行内按钮、主按钮）用 `--duration-instant`；**独立控件**（secondary / soft / ghost 按钮、独立图标按钮、tab、下拉触发器）用 `--duration-fast`。当前项移动、字符出现不做动画。由它们**间接引起**的显隐（行附件出现、打字时 chrome 淡出）按 `--duration-base` / `--duration-ambient`。
- 进出对称、可打断、不用 spring / 回弹。reduced-motion 下去掉缩放和位移，保留颜色 / 不透明度和 spinner（CSS 已处理）。

## 4. 禁止事项
- 同一视图出现两个及以上 primary；确认弹窗以外使用 danger；列表里逐行重复 soft / primary。
- hover 时位移、缩放、加阴影、改字重；选中项加粗；导航选中用强调色、左侧色条或下划线。
- 渐变背景（例外：骨架 shimmer；用同色 `linear-gradient` 叠两层底色不算渐变）、玻璃拟态（命令面板除外）；卡片套卡片；用描边卡片分组；卡片 / 线程 / 消息 / 引文加彩色边条。
- 用 emoji 当 UI 图标（用户给页面设的除外）；"emoji + 封面图"的大头部；插画。
- 颜色不克制：按主题 / 类型给图标上色；背景、正文、选中态、评论线程为了"醒目"变彩色；彩色整行底色（项目层在 `DESIGN.project.md` 里列为必需语义的除外）；评论锚点的黄色用到正文行内区间以外（整行、竖线、引文条）；脱离配套底色单独给状态 / 分类文字上色（`qp-msg`、`qp-tag` 底色上的配套文字色不算）。
- 头像用实心彩色圆底；用 AI 色或类别色给头像、作者名、AI 段落上色（D11）。
- 把 tertiary / disabled 灰用在需要读的文字上（D2）。
- 使用 Tabler 以外的图标库，或改图标线宽（D6）；引入品牌字体；代码字体换成更细的等宽字体（D8）。
- 居中对齐的长段落；正文列超过最大宽度（产品的"加宽"阅读设置除外）。
- 照搬参考产品的品牌元素：logo、AI 面孔、手绘插画、自有图标集、回弹的悬浮帮助按钮。
- 自己重写 `qp-` 类的外观；写死颜色 / px / ms；引用不存在的类或 token（lint 规则 color / unit / icon-lib / qp-override / qp-unknown / token-unknown；qp-new 只提示）。

## 5. 模式层 `[模式]`（默认值，PRODUCT 可覆盖）
- **布局**：侧边栏（工具行 → 搜索框 → 主入口 → 分组 → 文件树 → 工作区切换；可折叠，可在 `--layout-sidebar-min`–`-max` 间拖宽）+ 主区；正文列在主区水平居中；评论栏是正文右侧占版面的一列，不是浮层；详情侧板贴视口右缘。工作区切换 = `qp-row--nav` + `qp-iconbox` + `qp-row__label` + 末尾 chevron，不另建类。
- **空间不够时的收缩顺序**：视口窄于 `--breakpoint-wide` 时正文 / 表单列开始收缩 → 收到 `--layout-content-min`（视口约 `--breakpoint-comment`）仍放不下时，评论栏折成按钮、点开以浮层显示 → 窄于 `--breakpoint-compact` 时侧边栏变浮层、详情侧板全屏。侧边栏被拖宽后按主区容器宽度判断，不按视口。
- **专注**：用户键盘输入时，顶栏和行附件淡出，指针移动后恢复。
- **树**：hover 时对象图标原位变成展开 chevron，右侧出现 `+`、`···`；触屏上 `···` 常驻，长按行打开同一菜单。
- **表格**：行 hover 时左外沿出现拖拽柄和勾选框，标题格右侧出现 Open；子项缩进一级，每组末尾一行"+ Add sub-item"；空单元格不显示内容，详情面板里写"Empty"。
- **搜索结果**：两行（标题 + 元信息）。本地结果直接显示，远程结果超过 `--delay-loading` 才显示骨架行。
- **菜单**：插入菜单底部固定一行"Close menu · esc"。
- **弹窗**：左侧导航 + 右侧表单列，关闭按钮右上角。命令面板：左结果、右预览，底部提示栏写快捷键。
- **Drawer**：顶部工具行放"»"关闭、"↗"全屏打开；左侧内容保持可交互。
- **表单**：每行左"标签 + 说明"、右控件；分区标题下跟分隔线；开关和下拉即时保存，文本输入失焦保存；失焦时校验。
- **危险操作**：单个对象删除 / 移动直接执行 + Undo Toast；不可逆或批量操作弹确认框并要求输入对象名。
- **Toast**：`[对象图标] + 文案 + [Undo]`，左下角或底部居中，hover 暂停计时。
- **评论**：选中正文 → 选区旁出现悬浮工具条（离顶部太近时翻到下方）；线程在评论栏里与锚点垂直对齐，冲突时当前线程对齐、其余避让。
- **键盘**：Cmd/Ctrl+K 命令面板；`/` 插入菜单；↑↓ 移动当前项；Enter 执行；Ctrl+Enter 新标签打开；Esc 一次只关最上层一个浮层。一个列表同时只有一个高亮项，鼠标移动接管高亮。
- **代码块**：左上角语言名、右上角复制按钮（hover 出现）；代码以"版心里的块"呈现是文档页的默认形态。
- **移动端**：文件树是左侧抽屉；评论输入和线程用底部面板（下拖过面板高度的 `--sheet-dismiss-ratio` 或快速下甩关闭）；全屏搜索用不透明底并自动聚焦。

## 6. 文案语气
- 按钮 / 菜单项：动词开头，英文 2–3 词（Copy link），中文 2–4 字（复制链接；夹在中文里的英文词、缩写不计字数，如「问 AI」），不写人称、不加句号。
- 标签：名词短语，句首大写，不加冒号。说明文字：一句话说清"这个设置影响什么"，第二人称，句号结尾，≤ 2 行。
- 空状态："No + 名词" /「还没有 + 名词」，或"Press X to Y" /「按 X 以 Y」。
- 错误："发生了什么 + 怎么修复"，一句话，不写"Oops / Error:"。
- 元信息用"·"分隔，相对时间（Edited 6m ago / 6 分钟前 / 昨天 / 11 月 7 日）。中英文、数字之间加半角空格。

## 7. 已知不足（决定前不要自行补）
- 只有浅色模式；token 已按角色命名、派生值写成 `var()` 引用，暗色以后在 `[data-theme=dark]` 下重写源变量。
- 断点、触屏规则、Toast、Inline message、danger 按钮、确认弹窗、代码 / 公式 / 引用 / Markdown 表格的**组件组成与用法**是估计，没有采集或评审；它们所用 token 值的来源以 `tokens.css` 的逐值标签为准（`[估计]` 里有一部分是沿用早期原型的占位值，如 `--layout-modal-width-sm`）。
- Drawer、命令面板、移动端抽屉 / 底部面板的运动方式未采集，CSS 里统一用淡入（`qp-fade`）占位。命令面板的右侧预览区没有采集，所以没有类；样板只画结果列。
- 勾选框 / 开关没有 disabled 样式。表格单元格水平内边距借用 `--space-md`、开关旋钮借用 `--color-bg`：值本身是 `[测量]`，用在这两处是 `[推导]`。
