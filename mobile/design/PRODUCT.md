# PRODUCT.md — Reader

> 标记：【建议】= AI 补的默认值，用户还没拍板；【待定】= 还没想清楚，界面先用最简单的方案占位。
> 本文件回答"做什么、给谁、每页先给谁看什么"。视觉风格在 `style/`（quietpaper），这里不写。
> 由 `DECISIONS.md`（P1–P24）重建，不在末尾追加"修订"。总原则（P12）：沿用现有设计，除非指出了现有做法的具体问题。

## 1. 产品
- 一句话：用户自己（和少数熟人）用 Reader 在手机上**集中刷订阅和榜单的更新，并带翻译地读完**。
- 目标用户：用户本人为主，每天多次、碎片时间使用；熟悉自己的订阅；Android 手机竖屏（P6）。
- 核心任务（按重要性；现有功能全部保留，P7）：
  1. 刷订阅的新内容（今天有什么更新）
  2. 读文章 / 看视频，带翻译
  3. 看榜单，了解现在的热点
  4. 收藏，稍后读
  5. 管理订阅（添加、文件夹、是否出现在首页）
- 平台：Android 手机（Expo / React Native）；Web 只用于开发预览（P6）。
- 外观：浅色与深色两套，跟随系统（P20）；风格包 `style/`（quietpaper v0.7，P1）。【待定】风格包缺少的手机组件和深色变量怎么补（见第 5 节）。
- 不做什么：平板 / 宽屏布局；在 App 里做 AI 简报（Agent 通过 `/mcp` 做）；多账号或多服务器同时登录（P17）。

## 2. 信息架构
- 导航模型：底部 5 个标签（P14）+ 页面栈（Expo Router，P4）。文章、榜单条目从任何列表推入页面栈；返回时列表保持原来的滚动位置。
- 页面树：
```
/(auth)
├── /connect              连接服务器（地址 → 确认身份）
└── /sign-in              邮箱登录 / 注册
/(tabs)
├── /                     今天
├── /boards               榜单
├── /subscriptions        订阅
├── /saved                收藏
└── /me                   我的
/article/[id]             阅读页
/board-item               榜单条目预览（内容来自榜单快照）
```
  弹层（不是独立页面）：频道选择、添加订阅、文件夹编辑、榜单选项、编辑资料、修改密码、翻译语言 / 引擎选择、确认框。
- 全局元素：
  - 底部标签栏：列表页向下滚动时收起，向上滚动时出现（现状）。
  - 每个标签页有页头：标题和本页的主操作。
  - 连接或登录失效：页面顶部一条横幅，不弹窗（P17）。

## 3. 页面

### 3.1 今天 `/`
- **主任务**：看订阅里的新内容。
- **主操作**：点一条打开阅读页。次要操作：切换文件夹、频道选择（只看一个订阅）、下拉刷新、收藏。
- **内容优先级**：
  1. **信息流**：按 Reader 第一次看到的时间从新到旧（P8）。每条显示来源头像和名字、时间、标题（有译文时只显示译文，P15）、摘要、首图、右侧书签按钮（点一下收藏 / 取消，不打开内容，P19）。
     - **X 帖子**沿用现在的卡片：正文预览、回复 / 引用 / 转发关系有层级（P16）；自回复串显示"共 N 条"（P17）。
  2. **文件夹标签**：顶部一排"全部 + 各文件夹"，左右滑动切换（现状）。
  3. **频道选择**：从页头打开弹层，选一个订阅只看它（现状）；在订阅页点某个订阅也会进入这个状态。
- **布局骨架**：
```
┌────────────────────────────┐
│ 页头：今天          [频道]   │
│ [全部][AI][新闻][…] ← 可滑  │
├────────────────────────────┤
│ ○ 来源 · 2 小时前        🔖 │
│ 标题（译文）            [图] │
│ 摘要两行……                  │
├────────────────────────────┤
│ …                          │
├────────────────────────────┤
│ 今天  榜单  订阅  收藏  我的 │
└────────────────────────────┘
```
- **状态**：首次加载；空（还没有订阅 → 引导去添加 / 有订阅但还没内容）；加载失败（保留已显示的内容，可重试）；加载更多；只看一个订阅（页头显示订阅名和"清除"）；标题译文晚到（先显示原文，译好后替换，**行高不变**，P17）。
- **新内容角标**：看过一个订阅后，按后端序号标记"已看到这里"（现状）。
- **示例数据**：标题 10～200 字；来源名 2～40 字；无图 / 1 张图；摘要 0～280 字；X 串 1～12 条。

### 3.2 榜单 `/boards`
- **主任务**：看各平台现在的热点。
- **主操作**：打开一条榜单条目。次要操作：切换榜单、切换版本、手动刷新、收藏。
- **内容优先级**：
  1. **条目列表**，按排名。每个榜单有自己的卡片：
     - HN：分数、评论数、域名
     - GitHub：仓库名、简介、语言、星标、本期新增星标
     - Product Hunt：图标、简介、票数
     - Reddit：标题、图片、社区
     - TechTwitter：新闻标题、解读、话题标签、质量分（接口 2026-11 改版后没有推文原文、作者和互动数）
  2. **榜单切换**：顶部标签，左右滑动（现状）。
  3. **选项弹层**：GitHub 日 / 周 / 月；Product Hunt **今天 / 昨天两个按钮**（替代日历）；Reddit 社区（已订阅社区作快捷列表 + 输入任意社区，P17）和排序（热门 / 上升 / Top 日周月年）。
- **状态**：加载中（首次打开最多等约 10 秒）；**数据新旧**（"x 分钟前"）；**已过期**（刷新失败时显示旧数据并标明）；**暂停中**（被限流或人机验证，显示原因和预计恢复时间，P17）；空；失败。
- 背景：TechTwitter 自 2026-11-09 起对服务器请求要求浏览器验证，本机和线上都抓不到，暂时隐藏（P32）。

### 3.3 订阅 `/subscriptions`
- **主任务**：管理订阅。
- **主操作**：添加订阅。次要操作：搜索、按文件夹浏览、改文件夹、是否出现在首页、取消订阅（需确认）、点进某个订阅看它的内容（跳到"今天"并只看它，现状）。
- **内容优先级**：
  1. 订阅列表：头像、名字、类型、新内容数、**健康提示**（扫描失败、可能有遗漏；点开看原因，P17），按文件夹分组。
  2. 搜索框。
  3. 添加订阅弹层：选类型（RSS / 网站 / YouTube / X / Reddit），输入地址或账号，选文件夹（现状）。
- **状态**：空（引导添加）；搜索无结果；添加中；添加失败（找不到 RSS、地址不安全、网站连不上……，保留输入）；刚添加、等待首次扫描；取消订阅中。

### 3.4 收藏 `/saved`
- **主任务**：找到收藏过的内容读。
- **主操作**：打开一条。次要操作：按文件夹筛选（现状）、**搜索标题和摘要**（P17）、取消收藏。
- **内容**：按收藏时间从新到旧；从榜单收藏的条目也在这里（没有来源，显示榜单名）。
- **状态**：空；搜索无结果；加载失败；取消收藏后从列表移除。

### 3.5 我的 `/me`
- **主任务**：管理账号和阅读偏好。
- **内容（现状全部保留）**：
  - 账号：头像（选择 / 删除）、昵称、邮箱、修改密码、退出登录。
  - 阅读：翻译开关、目标语言、翻译引擎（显示哪些引擎可用）。
  - 界面语言（跟随系统 / 中文 / 英文）。
  - 外观：跟随系统（P20）；【待定】是否加手动切换"浅色 / 深色"。
  - 服务器：当前服务器；切换服务器 = 重新连接（P17）。
  - 关于。
- MCP 令牌：第一期用命令 `reader-admin mcp-token create|revoke`；App 里的管理界面在第二期（P18）。
- **状态**：资料保存中 / 失败（保留输入）；头像上传中 / 失败；修改密码时当前密码错误；翻译设置保存中 / 失败；引擎不可用（不能选）；退出登录确认。

### 3.6 阅读页 `/article/[id]`
- **主任务**：读完一条内容，需要时看翻译。
- **按来源**：
  - **网页文章**：默认原网页，可切换阅读模式（从原网页提取全文）；提取失败时提示，留在原网页（P13）。
  - **X、Reddit**：打开网页，可以看到评论和互动（P16）。
  - **YouTube**：播放器 + 同步字幕（可翻译），字幕时间轴可滚动；可打开 YouTube（P9、P16）。
- **翻译**：默认原文；可切换为双语（译文在原文下方、样式随原文）（P15、P24）。
- **全局操作**：返回、收藏、打开原链接 / 分享、翻译模式切换（悬浮工具条，现状）。
- **状态**：网页加载中 / 失败；阅读模式提取中 / 提取失败；翻译进行中（逐段出现）/ 部分失败 / 额度用完（显示多久后再试）；视频没有字幕；外链跳转确认（现状）。

### 3.7 榜单条目预览 `/board-item`
- **主任务**：看一条榜单条目的详情，决定要不要读原文。
- **内容**：标题和描述 / 解读（可翻译）、图片、数据（分数、星标、话题……）；"打开原文"（X、Reddit 打开网页）、"打开讨论区"（HN）；收藏（后端从快照复制条目）。
- **状态**：翻译进行中 / 失败；收藏中；收藏失败（榜单已刷新、这一条已不在快照里时提示）；没有图片。

### 3.8 连接与登录 `/connect` `/sign-in`
- 输入服务器地址 → 发现并确认服务器身份 → 邮箱登录或注册（现状）。
- 只记一个服务器（P17）。
- **状态**：发现中；地址无效 / 连不上（保留地址）；服务器身份需要确认；登录中；邮箱或密码错误；注册时邮箱已被使用；尝试过多（显示多久后再试）。

## 4. 核心流程

### 流程：首次使用
```
[未连接] --输入地址--> [发现中] --确认身份--> [未登录] --登录 / 注册--> [今天]
                         └--失败--> [连接错误，保留地址]
```

### 流程：读一篇网页文章并翻译
```
[今天] --点卡片--> [阅读页：原网页加载中] --加载完--> [原网页]
   [原网页] --切阅读模式--> [提取中] --成功--> [阅读模式] / --失败--> [原网页 + 提示]
   [任一模式] --切双语--> [翻译进行中，逐段出现] --完成--> [双语] / --额度用完--> [提示多久后再试]
   [阅读页] --返回--> [今天，回到原来的滚动位置]
```
- 可取消点：翻译进行中切回原文；离开页面时未完成的翻译不再显示（后端仍会完成，下次直接命中缓存）。

### 流程：添加订阅
```
[订阅] --添加--> [选类型 + 输入] --提交--> [添加中] --成功--> [列表出现新订阅：等待首次扫描]
                                              └--失败--> [显示原因，保留输入]
```

### 流程：打开榜单
```
[打开榜单] --快照新鲜--> [显示]
           --快照过期--> [加载中，最多约 10 秒] --成功--> [显示] / --超时或失败--> [显示旧数据，标明多久前]
           --暂停中--> [显示旧数据 + 暂停原因与预计恢复时间]
[显示] --手动刷新--> [1 分钟内重复点击：不重新抓取]
```
