# PRODUCT.md — Reader

> 标记：【建议】= AI 补的默认值，用户还没拍板；【待定】= 还没想清楚，界面先用最简单的方案占位。
> 本文件回答"做什么、给谁、每页先给谁看什么"。视觉风格在 `style/`（quietpaper），这里不写。
> 由 `DECISIONS.md` 重建，不在末尾追加"修订"。总原则（P12）：沿用现有设计，除非指出了现有做法的具体问题。

## 1. 产品
- 一句话：用户自己（和少数熟人）用 Reader 在手机上**集中刷订阅和榜单的更新，并带翻译地读完**。
- 目标用户：用户本人为主，每天多次、碎片时间使用；熟悉自己的订阅；Android 手机竖屏（P6）。
- 核心任务（按重要性，P7 全部保留）：
  1. 刷订阅的新内容（今天有什么更新）
  2. 读文章 / 看视频，带翻译
  3. 看榜单，了解现在的热点
  4. 收藏，稍后读
  5. 管理订阅（添加、文件夹、是否出现在首页）
- 平台：Android 手机（Expo / React Native）；Web 只用于开发预览（P6）。
- 使用的风格包：`style/`（quietpaper v0.7，P1）；手机组件待校准补充。
- 不做什么：平板 / 宽屏布局；在 App 里做 AI 简报（那是 Agent 通过 `/mcp` 做的事）；多账号同时登录。

## 2. 信息架构
- 导航模型：底部 5 个标签（P14）+ 页面栈（Expo Router）。文章、榜单条目从任何列表**推入**页面栈，返回时列表保持原来的滚动位置。
- 页面树（Expo Router 路由）：
```
/(auth)
├── /connect              连接服务器（地址、确认身份）
└── /sign-in              邮箱登录 / 注册
/(tabs)
├── /                     今天（首页信息流）
├── /boards               榜单
├── /subscriptions        订阅
├── /saved                收藏
└── /me                   我的
/article/[id]             阅读页（文章 / X / Reddit / YouTube 各自视图，P9 P13）
/board-item               榜单条目预览（从榜单进入，内容来自榜单快照）
```
  弹层（不是独立页面）：频道选择、添加订阅、文件夹编辑、榜单选项、编辑资料、修改密码、翻译语言 / 引擎选择、确认框。
- 全局元素：
  - 底部标签栏；在列表页向下滚动时收起，向上滚动时出现（现状）。
  - 每个标签页有页头：标题和本页的主操作。
  - 连接 / 登录失效时出现全局提示。【建议】统一做成页面顶部的一条横幅，不弹窗。

## 3. 页面

### 3.1 今天 `/`
- **主任务**：看订阅里的新内容。
- **主操作**：点一条打开阅读页。次要操作：按文件夹切换、选单个订阅（频道选择）、下拉刷新、收藏。
- **内容优先级**：
  1. 信息流：按 Reader 第一次看到的时间从新到旧（P8）。每条显示来源头像和名字、标题（有译文时显示译文，P15）、摘要、首图、时间；X 帖子显示正文预览、引用 / 转发、"共 N 条"串标记【建议：串标记是后端新提供的】。
  2. 顶部文件夹标签："全部"加各个文件夹，左右滑动切换（现状）。
  3. 频道选择：从页头打开弹层，选一个订阅只看它（现状）；从订阅页点某个订阅也会进入这个状态。
- **布局骨架**：
```
┌────────────────────────────┐
│ 页头：今天        [频道]     │
│ [全部][AI][新闻][…] ← 可滑  │
├────────────────────────────┤
│ ○ 来源 · 2 小时前            │
│ 标题（译文）            [图] │
│ 摘要两行……                  │
├────────────────────────────┤
│ …                          │
├────────────────────────────┤
│ 今天  榜单  订阅  收藏  我的 │
└────────────────────────────┘
```
- **状态**：首次加载；空（还没有订阅 → 引导去添加 / 有订阅但没内容）；加载失败（保留旧内容 + 可重试）；加载更多；单个订阅筛选中（页头显示订阅名和"清除"）；翻译进行中的标题（先显示原文，译好后替换；【建议】替换时不改变行高）。
- **新内容角标**：看过一个订阅后，按后端的序号标记"已看到这里"（现状）。
- **示例数据**：标题 10～200 字；来源名 2～40 字；无图 / 1 张图；摘要 0～280 字。

### 3.2 榜单 `/boards`
- **主任务**：看各平台现在的热点。
- **主操作**：打开一条榜单条目。次要操作：切换榜单、切换版本、刷新、收藏、打开讨论区。
- **内容优先级**：
  1. 榜单条目列表，按排名。每个榜单有自己的卡片：HN（分数、评论数、域名）、GitHub（仓库、语言、星标、本期新增星标）、Product Hunt（图标、简介、票数）、Reddit（标题、图片、社区）、TechTwitter（推文、图片）。
  2. 顶部榜单切换，左右滑动（现状）。
  3. 选项弹层：GitHub 日 / 周 / 月；Product Hunt **今天 / 昨天两个按钮**（替代日历，后端设计已定）；Reddit 社区和排序（热门 / 上升 / Top 日周月年）。
- **状态**：加载中（首次打开某个榜单最多等约 10 秒）；**已过期**（显示"x 分钟前的数据"，后端新提供）；暂停中（被限流 / 人机验证，显示原因和预计恢复时间）；空；失败。
- **【建议】Reddit 榜单可以看任何社区**：后端已去掉"先订阅才能看"。保留"已订阅的社区"作为快捷列表，另外加一个输入框。
- **【待定】TechTwitter**：接口现在被人机验证挡住，暂时显示"暂不可用"。

### 3.3 订阅 `/subscriptions`
- **主任务**：管理订阅。
- **主操作**：添加订阅。次要操作：搜索、按文件夹浏览、改文件夹、是否出现在首页、取消订阅（需确认）、点进某个订阅看它的内容（跳到首页并筛选，现状）。
- **内容优先级**：
  1. 订阅列表（头像、名字、类型、新内容数），按文件夹分组。
  2. 搜索框。
  3. 添加订阅弹层：选类型（RSS / 网站 / YouTube / X / Reddit），输入地址或账号，选文件夹（现状保留 5 种类型的选择，后端已合成一个接口）。
- **状态**：空（引导添加）；搜索无结果；添加中 / 添加失败（错误原因：找不到 RSS、地址不安全、网站连不上……）；取消订阅中。
- **【建议】订阅的健康状态**：后端新提供扫描失败原因和"可能有遗漏"标记。在列表行显示一个小提示，点开能看到原因。

### 3.4 收藏 `/saved`
- **主任务**：找到收藏过的内容读。
- **主操作**：打开一条。次要操作：按文件夹筛选（现状）、取消收藏、【建议】搜索（后端支持按标题和摘要搜索）。
- **内容优先级**：收藏列表，按收藏时间从新到旧；榜单里收藏的条目也在这里（没有来源，显示榜单名）。
- **状态**：空；加载失败；取消收藏后从列表移除。

### 3.5 我的 `/me`
- **主任务**：管理账号和阅读偏好。
- **内容（现状全部保留）**：
  - 账号：头像（选择 / 删除）、昵称、邮箱、修改密码、退出登录。
  - 阅读：翻译开关、目标语言、翻译引擎（显示哪些引擎可用）。
  - 界面语言（跟随系统 / 中文 / 英文）。
  - 服务器：当前服务器、切换服务器。
  - 关于。
- **【建议】MCP 令牌（第二期）**：在 App 里生成或撤销给 Agent 用的令牌。现在只能用 `reader-admin` 命令。

### 3.6 阅读页 `/article/[id]`
- **主任务**：读完一条内容，需要时看翻译。
- **按来源分四种视图**（P9 P13）：
  - **网页文章**：默认原网页，可切换阅读模式（从原网页提取全文）；翻译可选原文 / 双语 / 只看译文（P15）；提取失败时提示，留在原网页。
  - **X**：专门视图，显示帖子正文、图片、引用 / 转发、整串自回复；翻译直接显示在帖子下面。【建议：现状是打开 x.com 网页，这是 P9 带来的改动】
  - **Reddit**：专门视图，显示标题、正文、图片；可以打开原帖看评论。【建议：现状是网页】
  - **YouTube**：播放器 + 同步字幕（可翻译），字幕时间轴可滚动；可以打开 YouTube（现状）。
- **全局操作**：返回、收藏、打开原链接 / 分享、翻译模式切换（悬浮工具条，现状）。
- **状态**：网页加载中 / 失败；阅读模式提取中 / 提取失败；翻译进行中 / 部分失败 / 额度用完（显示多久后再试）；视频没有字幕；离开网页前的跳转确认（现状有外链确认）。

### 3.7 榜单条目预览 `/board-item`
- **主任务**：看一条榜单条目的详情，决定要不要读原文。
- **内容**：标题（可翻译）、描述 / 推文正文（可翻译）、图片、数据（分数、星标……）、"打开原文""打开讨论区"、收藏（后端从快照复制条目）。

### 3.8 连接与登录 `/connect` `/sign-in`
- 现状保留：输入服务器地址 → 发现并确认服务器身份 → 邮箱登录或注册。
- 【建议】连接层简化：单人使用，只记一个服务器；"切换服务器"就是重新连接。

## 4. 核心流程

### 流程：首次使用
```
[未连接] --输入地址--> [发现中] --确认身份--> [未登录] --登录 / 注册--> [今天]
                         └--失败--> [连接错误，保留地址]
```

### 流程：读一篇网页文章并翻译
```
[今天] --点卡片--> [阅读页：原网页加载中] --加载完--> [原网页]
   [原网页] --切阅读模式--> [提取中] --成功--> [阅读模式] / --失败--> [原网页 + 提示]
   [任一模式] --切双语--> [翻译进行中，逐段出现] --完成--> [双语] / --额度用完--> [提示多久后再试]
   [阅读页] --返回--> [今天，回到原来的滚动位置]
```
- 可取消点：翻译进行中切回原文；离开页面时未完成的翻译不再显示（后端仍会完成，下次直接命中缓存）。

### 流程：添加订阅
```
[订阅] --添加--> [选类型 + 输入] --提交--> [添加中] --成功--> [列表出现新订阅（状态：等待首次扫描）]
                                              └--失败--> [显示原因，保留输入]
```

### 流程：榜单刷新
```
[打开榜单] --快照新鲜--> [显示]
           --快照过期--> [加载中，最多约 10 秒] --成功--> [显示] / --超时或失败--> [显示旧数据 + "x 分钟前"]
[显示] --手动刷新--> [1 分钟内重复点击：不重新抓取]
```
